## Lesson sequence

Distinguish AI safety from security, then use the classroom examples to discuss red teaming, sycophancy, AI control, prompt injection, and collusion between agents. Connect each failure to something observable and a way to evaluate or limit it.

## Hackathon overview

The classroom slides introduce projects on agent interactions, trustworthy advice, agent attribution, threat analysis, and small-model training. The dates in the slide PDF are an archived classroom snapshot, not a maintained event calendar.

No new model-training or coding prerequisite is introduced in this meeting. Use the earlier ML work to explain what a model computes and why testing its behavior remains necessary.
