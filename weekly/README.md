# Weekly materials

Weeks follow Machine Learning Specialization, Course 1. Each folder contains printable handouts, editable source files, teaching notes, and a student notebook with a separate answer copy.

| Week | Subject | Suggested sequence |
| :--- | :--- | :--- |
| [01](week-01/README.md) | Linear regression and gradient descent | Predictions and costs, cost surface, update steps, optional labs, concept check |
| [02](week-02/README.md) | Multiple features and scaling | Predictions with several inputs, parameter updates, contours, scaling, optional labs |
| [03](week-03/README.md) | Sigmoid and logistic regression | Limits of linear predictions, sigmoid, decision boundary, MSE comparison, logistic loss |

The [combined notebooks](../common/course-1/README.md) are useful if you want all three weeks in one Colab. The week-specific copies use the same source cells.
