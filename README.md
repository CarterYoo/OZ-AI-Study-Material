# OZ AI Study Material

[English](README.md) · [한국어](README.ko.md)

Learning materials for building a Transformer from scratch, starting with the basics of machine learning.

## Weekly materials

| Week | Topics | Materials |
| :--- | :--- | :--- |
| W1 | Linear regression, cost functions, gradient descent | [Worksheets, answers, and Colab](weekly/week-01/README.md) |

Each week includes Korean and English worksheets, worked answers, concept checks, teaching notes, and Colab notebooks.

## Using the materials

Calculate and plot with the student worksheets, then compare your steps with the separate answer keys. Answers and graph marks are shown in red.

Open the notebooks in Colab and run the cells in order. Student exercises need one expression at a time; fill in each `TODO(...)` before running that cell.

Choose Korean or English on each material's page. PDFs are ready to print, PowerPoint files can be imported into Google Slides, and LaTeX sources are included for editing.
