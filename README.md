# OZ AI Study Material

[English](README.md) · [Korean materials](README.ko.md)

Learning materials for building a Transformer from scratch, starting with the basics of machine learning.

## Weekly materials

The six weeks follow the numbered lessons in the [OZ Lab classroom presentation](https://www.canva.com/design/DAHVe4UysZI/view).
Page numbers below refer to the combined 148-page Canva deck.

| Week | Topics | Canva pages | Materials |
| :--- | :--- | :--- | :--- |
| 01 | Orientation and the Transformer Roadmap | 1 to 8 | [Open](weekly/week-01/README.md) |
| 02 | Machine Learning Foundations | 9 to 42 | [Open](weekly/week-02/README.md) |
| 03 | Cost Functions and Gradient Descent | 43 to 73 | [Open](weekly/week-03/README.md) |
| 04 | Multiple Features and Feature Scaling | 74 to 107 | [Open](weekly/week-04/README.md) |
| 05 | Feature Engineering and Classification | 108 to 135 | [Open](weekly/week-05/README.md) |
| 06 | Technical AI Safety and Hackathon Overview | 136 to 148 | [Open](weekly/week-06/README.md) |

Each weekly page links its slide PDF, exercises, and supporting resources. Weeks 2 to 5 also include the editable OZ PowerPoint slides and English notes matched to the classroom pages. Existing Korean and English worksheets, worked answers, and Colab notebooks are retained.

## Using the materials

Start with the slide PDF on the weekly page. Use the worksheets for hand calculations and plotting, then compare the intermediate steps with the separate answer keys. Answers and graph marks are shown in red.

Open the notebooks in Colab and run the cells in order. Student exercises need one expression at a time; fill in each `TODO(...)` before running that cell.

The classroom slide PDFs preserve their original language. Bilingual worksheets and reference notes are labeled on each weekly page. Coursera's Course 1 weeks are source labels and differ from the six OZ study weeks above.
